# N02.3 局域网遥控请求关闭与拒绝响应

发布前完整门禁在安全用例的第二个超限POST出现响应头未完整收到。服务端已经消费一般POST并关闭响应；仅补齐客户端非持久请求没有消除失败。进一步用拆分发送16385字节并延迟结束符的用例，在原服务器实现稳定复现同类HttpException，固定实现通过。根因是超限首块直接抛错取消尚未结束的输入流，响应400可能来不及到达。

修正：普通请求16KiB、屏幕信令64KiB的接受上限不变；超限字节不存储，最多额外读取64KiB，10秒空闲超时并在读取中检查总耗时，超过预算中止；小幅超量体消耗完后回复400。原生客户端显式请求非持久连接，与每次响应关闭契约一致。没有放宽Origin、配对、错误次数、JSON大小或命令校验，也没有重试吞错。

验证：原安全失败保留、原服务器拆分请求反证失败；客户端旧9次请求均错误提供持久意图的反证保留；修正后整个remote_receiver目录17项通过，覆盖拆分超量、超过有限读取预算且服务仍可用、Origin/错误码/限额/无效命令。最终完整all/14与同源包重跑。
