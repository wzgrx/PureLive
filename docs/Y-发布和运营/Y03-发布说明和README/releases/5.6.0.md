# 5.6.0：新增反馈与需求统一更新

- 线路菜单统一标注编码与Raw，并显示CDN主机。Raw候选不借用转码编码，当前线有可靠原生统计后再显示实际编码；覆盖直播、全屏、TV、多画面、复制/投放和工具箱。
- 时间和直播流网速可分别设置位置、字号、字体及颜色；关闭独立设置后恢复原合并样式。小画面和大字号也会分配空间，避免互相重叠。
- 手机、平板和桌面增加自定义图片或纯色背景；电视背景设置也可从设备选择图片。支持适配、遮罩和清除，原图保留，图片在本机保存。
- 虎牙增加主播历史直播回放：从工具箱、电视链接放映或虎牙房间菜单进入，按场次选择、翻页、切清晰度并保存播放进度。
- 补齐虎牙聊天粉丝牌，B站粉丝牌使用平台提供的颜色、渐变和描边，跟随实际徽章变化。
- 屏幕共享的应用提示可选择完整、紧凑或隐藏，仍可在本机停止共享；系统隐私提示保持。改进默认浏览器的局域网屏幕连接协商，无需关闭浏览器隐私设置。
- 修复快手官方分享短链的解析和打开，搜索会使用已经保存的快手登录状态。游客搜索可能受平台限制，可登录后重试或粘贴官方分享链接。
- 集中修复电视关注空状态入口、历史和网络电视首次进入、筛选与卡片的上下关系、左右边界、返回房间的焦点记忆，以及菜单展开后的焦点可见性。
- 修正斗鱼非正金额、无效展示时间的语音通知被显示为额外醒目留言；保留真实付费消息和后续同文购买。
- 稳固局域网遥控超量请求的拒绝响应及连接关闭，限制读取和缓冲。
