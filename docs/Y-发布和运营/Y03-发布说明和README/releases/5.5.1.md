# 5.5.1：电视遥控焦点集中修复

- 修复空关注页从已开播、录播和未开播标签无法稳定进入搜索按钮，返回时恢复原标签。
- 修复历史和网络电视首次进入时，数据尚未返回导致焦点留在菜单；目标就绪后按当前页面和操作意图交接。
- 统一历史工具栏、筛选栏和房间卡片之间的上下关系，标签横向边界不再跳入其他层。
- 修复网络电视各行首列向左目标不一致，统一回到播放列表；管理按钮的下边界保持在当前列。
- 修复换台返回时旧焦点记忆覆盖指定房间，以及屏外卡片迟到请求抢走后续焦点。
- 修复返回历史和网络电视菜单后，菜单展开使焦点项被滚动视口裁掉；布局完成后显露当前焦点。
