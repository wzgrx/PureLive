# 5.6.3

- 小红书游客增强：读取官网直播分类、推荐和分页；独立原生连接接收实时弹幕、在线和累计观看更新。临时网页只用于游客初始化，退出后释放；Android隔离游客资料，不清理默认网页登录数据。#177
- 宽屏直播间：聊天收放按钮贴着聊天列边界；视频下方增加常驻信息栏，将人数、开播时长、画质、线路从聊天顶端移到视频底部。播放器沿用原会话与源比例。#180
- 屏蔽管理：新增只看彩色、最低用户等级、最低粉丝牌等级，默认不限；已屏蔽用户、关键词、属性、重复、相似和斗鱼疑似机器人过滤计入本场数量，同一传输重包不重复计数。平台未提供等级时不猜测为零。#181
- 移动数据提醒增加持久开关，横条“不再显示”保存到设置，之后可重新开启；离线检查照常生效。#182
- 画面方向和竖屏全屏画面模式统一为画质/线路一样的紧凑菜单，选中即生效；手机长按、电脑悬停查看原有说明，不误选、不关闭菜单。

安装包：Android按设备架构选择APK（常见手机arm64-v8a）；Windows提供安装包与便携版，Linux提供tar.gz，macOS提供dmg/zip，iOS提供unsigned/TrollStore IPA。SHA256SUMS记录同源包摘要。

范围：小红书当前实现游客观看的分类、目录和弹幕，未加入关键词全站搜索、账号互动、跨场主播跟踪和官方回放；Linux保留分享链接观看。旧Android WebView需要具备隔离资料区和完整清理能力；缺失时不退回共享资料。原反馈设备、Apple真机及各平台元数据缺失的边界在验收记录中保留。
