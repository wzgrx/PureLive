# 5.6.5

- Windows 安装更新时，如果桌面快捷方式仍指向同一个程序，保留原快捷方式和图标位置。#205
- 宽屏直播间增加视频底栏开关，默认保留原布局；关闭后人数、时长、画质和线路回到聊天栏上方，折叠聊天时仍可从播放控制条选择画质、线路。#180 / #216
- 多屏联动记住所选屏幕。点击按钮开关，右键重新选择；旧屏幕断开时提示重新选择。#214
- B 站关注列表使用已知身份批量刷新；缺项、身份不匹配或接口失败时回落原逐房间刷新。#204
- 全屏醒目留言入口随控制栏显示，未读状态不因隐藏丢失。#207
- Android 播放日志补充当前配置的解码器和输出模式，帮助排查绿屏及 TV 播放差异。#213 / #177

继续验证：斗鱼游客普通弹幕投递、原设备绿屏和小红书 TV 码流/解码差异尚未确认；CHZZK 已调查公开 HLS 与 DASH，成熟回放的 DASH 暂未交付；直播内回退仍需验证可寻址区间和缓存策略。
