# Pure Live 5.7.2

- 修复Windows多画面纹理注册并发崩溃，等待旧纹理完成退休再释放资源；分配失败保留有效画面，并同步真实纹理尺寸。
- 修复多画面搜索时键盘出现导致输入框重建、焦点丢失；修复Windows中文输入法影响播放快捷键，编辑时恢复原输入上下文。
- 修复抖音带末尾点号的合法直播间链接解析；斗鱼批量刷新更换为只读公开接口，未确认房间逐间回退，不修改平台账号关注。
- 修复斗鱼原画HEVC线路识别，保留服务端实际提供的编码与清晰度，不虚构播放地址或8M档位。
- 为电视回放补齐遥控暂停、快进后退、分集选择与返回焦点；保持同一播放会话和原小窗操作。
- 修复强制取消录制后未落盘尾段的恢复与MP4转封装，保留未成功合成的原始数据。
- 整合PR #235并补强弹幕解码队列的字节与帧数上限、输入背压、连接代际隔离和退出清理，避免高峰积压及旧连接消息混入。
- 为SOOP、Twitch、YouTube直播HLS复用有界分段预取，保持平台代理和请求头；回放和录制各自原有策略保持兼容。
- 改善小红书独立游客页面初始化与WebView能力错误提示，访客清理保持独立，不清除默认账号资料；复验旧B站关注首次补UID后的持久化批量刷新。

本版优先处理bug与稳定性，新增需求暂缓。斗鱼8M缺少同房样本，当前游客接口样本没有返回该档位；原小红书电视盒子的慢动作、海外平台原账号/网络仍保留独立复验，相关问题不因候选修复自动关闭。Windows生成媒体原生压力、受控慢HLS、Android独立模拟器和Apple CI证据分别记录，不承诺所有实体硬件或账号均已覆盖。

工具链与内核沿用5.7.1已验证版本；Android三架构、Windows便携与安装、Linux、iOS两个包和macOS两个包从同一冻结源码构建。关注、设置、历史和备份格式保持兼容。
