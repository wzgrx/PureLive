# 5.7.0

本次升级开发工具链、直接依赖和播放/录制内核，并交付此前本地候选中的功能与修正。客户端保持原包名及数据升级路径。

## 工程和兼容

- Flutter3.50.1、Dart3.14、Gradle9.9.2、AGP9.5.2、JDK27.0.1.1+4；更新Clang、CMake、Visual Studio、Inno Setup、Android平台工具与Apple工具链。准确版本见toolchain.env。
- 现有发布客户端统一使用mpv0.42；录制FFmpeg9.1。Windows播放使用官方mpv0.42包及其内置FFmpeg快照；自建播放包的版本和来源分别记录。
- 适配Material/Cupertino分离、完整主题继承、Windows隐藏主窗口绑定、显式显示和首屏刷新，以及文件夹URI，保持小窗和窗口生命周期。播放器信息在精简内核没有长描述时使用实际编码短名。
- Android和Linux接入系统证书信任，保持TLS验证；受信任HTTPS正常播放，未知证书拒绝，显式CA来源保留。

## 已有候选的改进

- B站关注刷新保留主播身份，直播卡片优先当前关键帧；斗鱼批量确认普通未开播状态，保留不明确状态的逐房核对。#221 #224 #222
- 画质和线路可选择放在播放器控制栏，默认关闭；宽屏回放折叠聊天时保留控制入口。#220
- 增加独立房间列表及主动开启的轮播、默认关闭的画面长按切房、TV双画面和前台直播间预约；保留单音源与会话释放。
- 直播缓存回看默认关闭，仅回看当前会话仍在内存中的连续范围；CHZZK公开回放使用校验过的VOD分段，改善续看和拖动。不是整场回放录制或应用退出后的定时拉起。
- 修正过期醒目留言、斗鱼延迟实时聊天及预约替换；小红书访客初始化保留阶段、能力与原生清理回执。#177原设备差异继续追踪。

## 验证范围

源码、门禁、原生探针、安装包和原设备验收分别记录。Android模拟器及隔离桌面/Apple云端验证用于本轮发布；未取得原ARM手机、电视盒和iPhone/iPad真机结果的现象继续保留，不宣称全部硬件问题已修复。


原生来源与完整校验：[播放内核](https://github.com/wzgrx/PureLive/releases/tag/native-libmpv-0.42.0-ff9.1-b1)、[录制内核](https://github.com/wzgrx/PureLive/releases/tag/native-ffmpeg-9.1-b1)。Apple五架构来自同一源码与补丁，原生二进制最低系统仍为iOS15/macOS12。Linux整个客户端需要glibc2.38和GLIBCXX3.4.32，与5.6.5分发插件相同，已补充到下载说明。

工作区直接依赖采用当前官方版本；六项Dart间接依赖保留SDK/上游可解算约束。SDK语义回归保留上游原始断言，在隔离的非图像测试环境执行。
