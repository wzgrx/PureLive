# 5.6.2：原直播间回放与维护恢复

- 恢复功能需求表单和维护者开发，用户可提交新功能请求，无需先自带PR。撤销旧维护收缩置顶公告，公开回放继续维护。
- 斗鱼、虎牙、哔哩哔哩公开回放沿用原直播间横竖屏与小窗体系，加入场次/分段、时间排序、续看、0.25～4×预设及0.05×微调；保持同一会话，实时弹幕不混入录制。
- 修复回放异步数据到达后按钮/分段不刷新、标签动画与小尺寸布局，补齐横屏倍速面板背景；返回直播恢复正常速度。
- 修复虎牙长回放跨HLS时间戳断点拖动卡住：从目标附近分片重新建立播放入口，保持完整回放时钟、暂停/音量/倍速及站点代理；进度确认仍有上限，不把未确认目标写进观看进度。
- Windows安装更新在写入前协作关闭相同安装路径的运行实例，绕过托盘关闭策略；停止失败时在替换文件前中止，不按进程名强杀其他安装。
- 去掉IPTV多列表当前项的额外常驻选择框，保留“热门显示中”状态标签和电视真实焦点。
- 虎牙粉丝牌等级使用独立色带回退，服务器提供原生颜色时仍优先；不是官方定制徽章皮肤复刻。

同源构建、门禁与实际验证范围见Y01.42/verify.md；物理设备、未覆盖账号/VIP及CDN不由软件回归代验。预览客户端发行在正式版交付核验后清理，原生构建依赖与正式历史保留。


- 支持导入自己的TTF/OTF字体：在应用或弹幕字体页点“导入”，各自选择；原文件保留，重复内容自动去重。
- 修复部分旧安卓系统因播放器依赖Vulkan新接口而初始化失败，避免播放器及后续插件加载中断。已做API27 x64模拟器执行和三ABI静态检查，原反馈设备仍需用户复验。

- 修复开启播放代理时回放拖动、续看的本机分片入口误走代理，外部视频分片仍按用户代理设置请求。

- 修复1＋3多画面在全屏或沉浸时主画面顶部按钮、主播标识未与底部操作栏同步隐藏；点击主画面可重新唤出，副画面标识保留，切换不重建播放器。
