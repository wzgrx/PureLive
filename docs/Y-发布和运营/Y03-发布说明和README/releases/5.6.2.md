- 去掉IPTV多列表当前项的额外常驻选择框，保留“热门显示中”状态标签和电视真实焦点。
- 虎牙粉丝牌等级使用独立色带回退，服务器提供原生颜色时仍优先；不是官方定制徽章皮肤复刻。
