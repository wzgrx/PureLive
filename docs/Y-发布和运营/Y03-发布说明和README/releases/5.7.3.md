# Pure Live 5.7.3

- 修复Linux自5.7.0起部分桌面环境直播画面正常但完全无声的问题：默认恢复内核音频设备探测，避免强制ALSA加载构建机插件目录。
- 修复专家音频输出中的auto和空值处理，按各平台默认方式选择；明确选择的驱动、禁音及Android回退策略保留。
- 补充Ubuntu24.04.5正式新旧库对照和真实应用音频回路验收，验证生成440Hz音频的非零PCM输出，避免仅凭视频画面判断声音正常。

本版聚焦#266音频回归，关注、设置、历史及备份格式保持兼容。普通Linux用户可保留默认设置；此前为临时绕过而启用专家输出的用户可关闭该开关恢复自动选择，明确指定ALSA的用户仍按所选驱动运行。原用户物理声卡尚未远程实测，已在相同Ubuntu24.04.5用户态及独立音频服务中复现并验证修复。

Android三架构、Windows便携与安装、Linux、iOS两包和macOS两包由同一冻结源码构建；现有5.7.2包不替换。
