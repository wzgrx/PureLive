# 5.6.4

- 竖屏全屏弹幕新增左下角向上滚动布局，可在设置选择；升级后默认保留原来的横向弹幕，沿用字体、透明度、屏蔽、表情及长按操作。#193
- 回放列表接近底部自动继续加载，增加标题/主播关键词搜索、今天/昨天/近3天/7天/30天/90天/一年及自定义日期范围。搜索会逐步检索当前主播或选定合集，显示已检索数量；沿用原横竖屏播放器、小窗、续看、分段与倍速。
- SOOP新增公开直播回放，在原直播间回放界面查看主播录像和实际分段，选择平台提供的画质，保存本地分段进度。#196
- SOOP增加多个官方CDN线路，保留服务器分配顺序，移除重复地址；部分分配失败仍保留可用线路，并限制并发和等待时间。#195
- 网易CC接入原生游客文字弹幕和在线人数；补充按当前主播过滤的礼物消息解析。旧参考注册类型和浮点路由参数与当前官网不一致，本次按实际成功入房流程接入。#198
- 修复Android应用内小窗绕过“离开应用自动小窗”开关；移除应用任务时清理播放、通知及外部窗口。补上退出时的画中画接收器泄漏、重复音频状态写入和缓存状态清理。#194
- 小红书首次弹幕初始化与视频打开同时启动，减少两段等待叠加造成的连接延迟。#177
- 补充抖音礼物消息及连击总量解析，保留快手接口明确返回的礼物文字；没有提供的价格、图标和元数据保持未知。#192

安装包：Android按设备架构选择APK（常见手机arm64-v8a）；Windows提供安装包与便携版，Linux提供tar.gz，macOS提供dmg/zip，iOS提供unsigned/TrollStore IPA。SHA256SUMS记录同源包摘要。

验证边界：SOOP此次支持公开回放，不代替私密、付费或年龄认证；搜索范围为当前主播/合集，非全站搜索。小红书TV微卡顿仍待原设备验证，平台仅返回原画的房间仍只显示原画。抖音/快手登录态真实礼物投递、快手完整价图目录，以及CC礼物真实投递与完整目录仍继续跟进，相关问题不冒充全部完成。Android任务清理已在独立API37模拟器验证，原Honor/MagicOS和Apple真机仍有各自复验边界。
