# #175 本地字体导入设计

沿用实际字体管理页与设置组件，不改变直播间布局。受众是想导入自己字体的手机和桌面用户；主任务是选择文件、看见本地字体、明确点击使用，并能恢复系统字体。

视觉参考为应用现有主题角色，颜色随用户主题变化。默认浅色参考：背景`#F8F7FC`、内容`#191C20`、主操作`#0057D9`、次要底色`#E2E3ED`、轮廓`#74777F`、错误`#BA1A1A`。字体、圆角、间距和焦点沿用Theme与Settings组件；标题/正文/说明保持现有层级，列表左对齐，不引入额外装饰或自动动效。

选用原页内导入：工具栏文字动作“导入”，系统字体之后、本地字体先于云端字体。另起导入向导会增加这项单文件操作的导航成本，不选用。

```text
返回  字体                         导入  文件夹
系统字体
  系统默认                             使用中
本地字体（n）
  用户文件名                 使用 / 更多→删除
  支持TTF、OTF，单文件最大64MB
云端字体（保留原有下载、取消和字重选择）
```

导入后列出字体，保持原选择，用户点击“使用”才切换。应用字体与弹幕字体共用导入文件，选择各自独立；删除字体时使用该字体的两处设置均回到系统默认。以内容摘要去重，文件复制到应用字体目录，删除原文件或重启不影响已导入字体。取消选择不改变任何设置。

文件类型、字体头与表边界、64MB上限、损坏文件、复制失败和重复导入分别处理。导入中禁用冲突操作，完成后给出可理解的反馈，不显示内部目录或哈希。低宽度、横屏、桌面、TV焦点和大字状态走原有设置布局；实现后检查实际渲染、导入与取消、应用、重启保留、删除回退，不以示意图代替实际界面。
