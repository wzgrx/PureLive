# A11.11 手机和桌面自定义背景

来源：#143。

手机和桌面支持本地图片、颜色、适配方式、遮罩和清除；默认关闭，原生选择器导入并复制受控文件，限制解码尺寸；保留电视既有背景功能，不引入额外视频解码器。

用户授权所有决定自行处理，按本方案推进，无需重复确认。系统权限仍由系统处理。

## 各布局

手机使用设置列表和标准返回，桌面复用设置面板，电视保留遥控焦点和返回边界。用户可见新文字进入zh/en有序翻译。默认外观保持不变，配置不持有账号、Cookie或媒体签名。

## 验收

实际协议或官方响应证据、对应回归、必要的修改前失败、受控原生布局与运行验证。原设备未覆盖与受控证据分开记录。

## 实现要点

手机和桌面通过Settings.customBackground共用本地图片/纯色、适配、主题遮罩和清除入口；默认关闭。电视原背景设置增加从设备选图片，继续复用电视既有适配/遮罩/一次性模糊。两者新文件均写入当前AppServices.dataRoot，隔离便携/测试实例。

系统文件选择器返回文件后，编码上限20MiB、源像素上限8000万；解码首帧缩小至最长2560且至多600万像素，存静态PNG副本。只保存受控basename，禁止导入设置读取任意路径。原图保留，清理只针对自身生成文件；电视当前原图与模糊图均保留直到替换，取消选择保持原背景。模糊图像、绘图命令和编解码器有明确释放。备份不携带图片，换设备重新选图；缺文件回退主题。

根层只让Scaffold背景透明，卡片/对话框表面保留，默认70%主题遮罩；不增加视频解码器。模型/副本尺寸/超量损坏输入/原图保留/背景清除/输入透传及TV本地选择-模糊调整-取消-清除回归通过。
