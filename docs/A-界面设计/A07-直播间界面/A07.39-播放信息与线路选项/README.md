# 播放信息与线路显示选项

来源：用户明确要求暂停发布，调整常驻播放信息和线路详情默认行为。5.6.0已恢复草稿；新旧仓库更新JSON仍为5.5.0。此任务只开发与验证，不推进发布、更新JSON或关闭issue。

手机竖屏不显示播放信息；横屏全屏默认以11px紧凑文字放到左上角电池旁，时间与可选流速使用同一状态行。新增默认的“全屏常驻”模式；已有明确的常驻或跟随控制栏设置保留，避免重复电池和重复时钟；已有自定义独立样式保留。非全屏手机画面不再浮出这层信息。浮层不拦截点击，保留大字与缺电池设备布局。

新增全局“线路详细信息”开关，默认关闭。旧版本没有此键，升级后自然为关闭；不根据Raw开关或旧配置自动启用。关闭时各选择入口只显示线路1/2/3并隐藏额外CDN描述，且不启动额外编码探测；开启后统一显示编码、Raw、CDN，保留真实编码与迟到回调保护。选择索引、取流、复制与投屏地址不变。
