# A15.5 沿用直播间的回放模式：任务书

来源：维护者要求回放在原横竖屏直播界面上增加UI，保留小窗等原功能，查看实际截图基底的增量设计后要求“生成测试包”。D-091限定本次实现和Android预览交付，不改变D-088其他功能冻结。

## 目标

1. 回放进入原LivePlayPage、RoomPlayer、RoomHeader和RoomPanel体系，不能继续另造播放器外壳。
2. 原直播间内选回放时保留同一个PlaybackSession；停止直播刷新/实时弹幕，再接入独立ArchivePlaybackController，返回直播恢复原解析。
3. 视频原控制栏上方新增进度，原信息栏增加倍速/回放目录，原标签增加回放列表。横屏设置沿原侧栏；锁定和小窗不显示多余回放控件。
4. 悬浮窗、系统PiP、桌面小窗复用原RoomRuntime；缩小/恢复保留会话、倍率、暂停意图与进度。API实例在页销毁前捕获，浮窗不可访问已销毁ref。
5. 各平台回放解析、分P/分段进度与有权限的画质保持。实时弹幕、历史弹幕、醒目留言不能混淆；无历史数据准确空态。不能把回放的投屏/录制入口误连直播源。

## 范围与阶段

直播间、回放入口、共享archive、路由、对应测试与文档；两个阶段：共享会话及原UI接入；回归/原生QA及Android v4dev预览。禁止稳定版本号和两份更新JSON、签名、正式版数据改动。不操作用户手机。

## 验证

离线fake验证直播/回放切换、异步取消、资源所有权、浮窗还原、倍率/暂停/分段、原直播回归；393×852、740×360、852×393、1280×800及大字布局。完整all/14推送前通过；本地双ABI构建；独占模拟器实际UI和小窗操作，安装APK哈希与候选一致。物理手机/TV、账号/VIP与真实听音未验则保持待真机。
