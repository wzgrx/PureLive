# A15.4 回放第五版预览：任务书

来源：维护者要求重新优化回放竖横屏，确认第五版设计后明确要求“构建发布测试版本”。本轮沿用D-089的公开回放范围，仅发布Android v4dev预览，正式通道保持5.6.1。

## 目标与范围

1. 竖屏保留创作者页头，播放、快进退、进度与全屏留在16:9画面内；短标题、日期、整场时长、倍速/画质/更多及分段列表紧接画面。
2. 横屏播放时3秒隐藏控件；暂停、键盘导航和设置侧栏保留操作。一个设置层覆盖画面，不改变视频尺寸。返回先关设置，再退出全屏，再回目录。
3. 共享12档预设和0.05微调，草稿取消不改变播放倍率。音量滑条收进更多；分段进度和暂停意图保持。
4. 固定主播目录默认不显示房间号表单；另开查询入口。相关场次切换先释放旧解码器，Back必须等待资源退役。
5. 翻译键齐全；只改共享archive、features/replay、相关测试与文档。禁止修改稳定更新JSON、版本基线、正式包数据和签名配置。

## 先读与基线

AGENTS.md、MAINTENANCE.md、PROCESS第4/8/14节、ENGINEERING、UI；C03.4已有公开回放解析与播放控制器。3.x的全屏、暂停、倍速和按返回离开的习惯保留，沿用当前PlaybackSession与进度存储，不重写解析接口。

## 验证

三平台目录和播放器、393×852/740×360/1280×800与200%文字、浅色对比度、方向键、侧栏尺寸、倍率取消和延迟退役自动回归。完整all/14门禁后本地构建；在任务独占模拟器运行真实API回放并截图。物理手机/电视、音频听感和Apple未验收，任务不能记完成。

## 阶段

共享布局与生命周期完成后，经完整门禁审查合并，再交付有独立版本标识、哈希与签名记录的GitHub预览包。提交前缀[A15.4]，分支ai/A15.4-replay-v5。
