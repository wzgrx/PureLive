# A15.4 回放第五版预览

使用frontend-design和art-direction梳理层级，按维护者已查看的第五版原型实现原生Flutter布局。原型存于本机outputs/purelive-replay-redesign-v5-20261103；实际界面必须由新APK验收，不用HTML截图代替。

| 界面 | 入口 | 形态及状态 |
|---|---|---|
| 主播目录 | 直播间标题/工具箱 | 创作者固定、日期过滤、续看、加载/失败/空态/分页 |
| 其他回放查询 | 目录页头 | 独立平台/链接表单，不冒用原主播名称 |
| 竖屏播放器 | 场次行 | 视频内控制；标题日期整场时长与分段连续排列 |
| 横屏播放器 | 旋转/全屏 | 3秒隐藏；暂停/错误/键盘操作不隐藏 |
| 倍速/画质/场次/更多/弹幕设置 | 工具行 | 同一页内底部或右侧设置层，返回先关闭 |
| 相关场次 | 主播回放标签 | 等旧会话退役后创建新会话，避免双解码器 |

可见短标题仅移除重复的回放/日期/作者包装，原始metadata和播放ID不变。B站保存分段内进度并明确标注，不能冒充整场进度。媒体封面来自API；设计用真实参考帧没有打包进应用。

UI代码和设计由本次Codex执行，未借用或宣称Opus验证；维护者直接授权本轮实现和测试版发布。除中文简繁/英文外新增键使用英文回退，其余既有翻译保留。
