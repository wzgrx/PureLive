# A17.29 电视焦点区域与异步入场

来源：#141、#142；复核96条反馈中41条电视及共享交互相关条目及143条评论。

范围：电视首页首次异步入场、隐藏页面输入隔离、空状态可达、筛选栏/操作栏/卡片和IPTV两栏的逻辑方向关系。保持已修复的设置首行、弹窗首焦、返回层级与焦点绘制。

不得改变播放器内核、账号凭据、用户正式安装和数据；不将#131/#135原场景及已暂缓#33/#49宣称修复。不承诺未来零缺陷。

验收：先保留原实现失败的遥控按键回归，再覆盖冷/热入场、延迟加载、空/有数据、离开/弹窗期间迟到数据、隐藏页面、横向边界与纵向层级。定向测试、完整TV测试、分析和all/14门禁；专用AVD原生复核与原Sony真机结果分开记录。没有原机证据的保持待验证。
