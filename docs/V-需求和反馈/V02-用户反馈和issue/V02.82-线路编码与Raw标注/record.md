# V02.82 线路编码与Raw标注

新#152要求所有端的线路菜单显示视频编码与Raw，当前活动线路也能辨认。5.5.0已保留LivePlayLine.codec和raw|lineId，但控件只展示索引，工具箱和复制/投放面板还把解析结果缩成URL列表，丢掉了描述信息。

共用playback_lines.dart生成核心标注，官方codec正常映射；Raw起播前只显示raw，不从转码档编码推断原始流。当前线在解码画面就绪后，最多3秒读取现有原生统计；与房间HUD复用一个采样器，停止、换源、重开、过期异步结果均不能把旧编码带到新线。没有可靠证据保持未知；不访问其他线路探测、不重排或换URL。

控制条、全屏、TV、多画面、复制/投放、工具箱全部保留元数据并用同一核心标签。展开菜单补充纯CDN主机名，不暴露路径、签名或请求头；工具箱原有主动复制URL流程保留。窄屏按钮可收缩，展开菜单显示完整描述。未知、非HTTP来源不制造CDN信息。用户已授权自主决定，沿用现有组件，设计自审无需重复确认。

验收：真实/未知编码、Raw转码提示不误用、源身份隔离、懒采样及3秒上限、选择索引/URL不变、各布局一致和大字窄屏不溢出。原生关键路径和同源十包仍须在最终源码通过完整all/14后执行。

## #152 实现与回归

同一playbackLineName生成所有线路核心标签，官方声明编码映射H.264/H.265/AV1/VP8/VP9，Raw起播前仅raw；只接受当前已解码输入的原生video-format/video-codec证据，不使用转码档暗示。候选次序、索引、URL及选中回调保持；复制/投放及工具箱保留LivePlayLine元数据，不再先缩成URL列表。展开选择列表显示纯CDN主机，路径、签名、用户信息和请求头不进入主机描述。

共用统计与房间HUD同一个采样器，最大3秒查询窗口，未知保持未知，视图移除或源变化停止。缓存和异步结果的归属包含engine/source/line/owned input，同一个计划重开也会失效。没有新播放器内核、额外线路网络探测、默认Raw开关或自动选线策略变化。窄屏按钮允许省略，展开菜单会自然换行并显示完整描述。
