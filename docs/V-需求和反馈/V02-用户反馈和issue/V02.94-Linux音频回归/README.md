# Linux音频回归 #266

反馈Ubuntu24.04.5，5.6.5有声，覆盖5.7.0/5.7.2后多个平台有画面无声，切换静音和音量不恢复，回退5.6.5即恢复。优先核对应用AO策略、原生内核/ALSA插件加载和打包差异，不归因用户硬件或网络。

当前发现：新旧Dart配置均强制Linux ao=alsa；5.7.0升级的自构建0.42内核静态链接ALSA，其二进制插件目录含构建机/workspace/prebuilt/linux-x86_64/libraries/lib/alsa-lib。Pulse后端已编入，原生音频输出选择仍需实际波形复现。以正式5.6.5/5.7.2包抽出的库、独立音频服务/虚拟设备、生成音频验证，禁止只以播放状态或视频截图宣称出声。
