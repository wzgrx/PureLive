# C03.3 虎牙历史直播回放

来源：#148。

读取官方主播视频主页直播录像列表和分页，选择录制场次后复用现有点播质量、进度和播放能力；无登录或付费绕过，空列表与接口失败可重试，手机桌面电视入口一致。

用户授权所有决定自行处理，按本方案推进，无需重复确认。系统权限仍由系统处理。

## 各布局

手机使用设置列表和标准返回，桌面复用设置面板，电视保留遥控焦点和返回边界。用户可见新文字进入zh/en有序翻译。默认外观保持不变，配置不持有账号、Cookie或媒体签名。

## 验收

实际协议或官方响应证据、对应回归、必要的修改前失败、受控原生布局与运行验证。原设备未覆盖与受控证据分开记录。

## 实现要点

已按用户给出的官方主页抓取两页公开录像和getMomentContent。匿名HTTP页面的HNF_GLOBAL_INIT含Tars协议元数据函数，应用只提取目标数据对象、丢弃已知_proto/_read/_write元数据后按JSON解码；不执行远程JS。2页各10场、总57场，场次不同，第一场1131139550与第二页1129574858；当前接口返回三档清晰度。提交fixtures保留公开响应形状，去掉无关网页/遥测状态，播放地址替为合成地址。

手机/桌面工具箱、TV链接放映和虎牙直播间菜单均可打开共享目录，输入房间号或官方录像主页链接，分页、失败重试和空列表明确。播放器复用原斗鱼VOD控制面板，通过ArchivePlaybackController抽象共用控件；两平台仍独立解析、进度与请求头。虎牙录像以onDemand打开，有进度/清晰度/暂停与音量保持，异步过期请求和页面退出不会再开媒体；不把当前直播弹幕投到历史录像。进度只存id和毫秒，200条上限，没有签名或媒体地址。原直播打开回放前停播，回到原身份且原会话仍由此操作持有时再恢复；等实际native disposal后交还解码资源。
