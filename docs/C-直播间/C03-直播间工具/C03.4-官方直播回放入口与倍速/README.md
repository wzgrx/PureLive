依据：D-089，维护者在本轮直接要求恢复这部分回放设计实现，修复匿名昵称和常驻提示。其他功能仍按D-088。

## 范围和基线

- UI沿用维护者要求重新生成的第四版日期目录、12档速度及0.05精调方案，使用frontend-design与art-direction，先检查真实5.6.1截图再实现。
- 已有虎牙与斗鱼回放不删除，旧路由和进度键保留。统一目录新增哔哩哔哩的创作者公开回放系列，不把普通投稿全都标作回放。
- 当前原生倍速边界0.25～4；选择预设直接应用，精调仅明确应用后生效，关闭丢弃草稿。
- 历史提交b041ab0c1确认过游客完整昵称，不应仅因为没有Cookie就提示隐藏。当前匿名实测存在完整与服务端全字段打码两种结果，不能混作客户端漏字段。

## 验收

1. 房间标题、菜单、工具箱的回放入口共用平台能力判断；不支持的平台不出现虚假入口。
2. 房间号独立解析主播身份，不能把房间号直接当UID；列表可分页、重试、切合集，晚返回不能写入新页面。
3. B站分P和DASH音轨走已有点播媒体合同；画质切换保留位置、暂停、音量与倍速；退出等待原生播放器释放。
4. 匿名报文存在完整昵称字段时直接显示，不以登录为条件。主字段打码但origin_info.name完整时不漏取。全字段打码时保留真实打码，不能伪造名字或以头像关联猜身份。
5. 提示可关闭、8秒收起，同一房间访问重连与旋转不重复弹；关闭“显示用户名”时无多余提示。
6. 覆盖手机竖屏、740×360横屏、桌面和大字、错误、空、加载、焦点相关状态；测试不访问真实平台，实际只读接口巡检单独记证据。
