# X01.7 安装更新保留已有桌面快捷方式

安装器反复写同目标 .lnk 会使桌面重新放置。读取目标并比较规范路径，同目标跳过 Save，不同目标按用户选中的任务更新。独立 AppId 和测试桌面验证缺失创建、同目标字节不变、不同目标更新；未写正式安装和真实桌面。
